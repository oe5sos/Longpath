# App: drei Layout-Entwürfe, zweite Fassung (2026-11-21)

Martin zur ersten Fassung ([2026-11-21-layout](../2026-11-21-layout/)): „das ist
alles orange". Zu Recht — HAUSSTIL: **Blau = anfassbar, Warm = gemessen.**

Was sich geändert hat (Aufteilung bleibt wie in der ersten Fassung):

* **Warm nur für Messwerte:** S-Meter-Balken und -Wert, Spektrumkurve und
  dBm-Zahlen. Sonst nichts Orangenes.
* **Frequenz neutral hell** (Glaschip), Band/Spanne neben der Frequenz und
  Reglerwerte neutral.
* **Bedienelemente neutral:** LOG, TUNE und ENTSICHERN sind graue Glasknöpfe;
  SCHARF ist eine Mulde (kein Blau, kein Orange). Auswahl bleibt Mulde.
* **Messing nur für SENDEN.** Kein Rot.
