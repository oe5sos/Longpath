# RIT/XIT und Abstimmschritt (Blatt, 2026-11-25)

Echte Seite gegen `attrappe.py` (RIT ein, +120 Hz; XIT aus).

* **iPhone** ([iphone-393.png](iphone-393.png)): neues Feld unter Filter/Aufbereitung —
  Schritt 10 Hz / 100 Hz / 1 kHz, darunter je eine Zeile wie am Mac:
  `[RIT] [0] [◀] Versatz [▶]`, ebenso XIT. Der Schritt gilt auch für die ± im Panadapter.
* **Desktop** ([desktop-1400.png](desktop-1400.png)): Schritt bleibt in der Pillenleiste,
  RIT/XIT stehen in „Combined" unter Filterbreite und Schritt.

Der Versatz ist orange, solange RIT/XIT an ist, sonst grau. ◀/▶ schieben um den
Schritt, Grenze ±10 kHz (wie RxApplet). Ein/aus und Wert zeigt die Seite nur so,
wie Longpath sie meldet (`rit_enable`, `rit_offset`, `xit_enable`, `xit_offset`).
