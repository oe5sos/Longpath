# Filterkanten ziehen (Blatt, 2026-11-25)

Echte Seite gegen `attrappe.py`, Ausschnitt 12 kHz, mitten im Ziehen der oberen Kante.

* An beiden Kanten des Durchlasses ein Griff (schmaler orangefarbener Strich, Knopf im
  Panadapter, Trefferfläche 24 px). Ziehen mit Finger oder Maus verschiebt die Kante.
* Während des Ziehens steht die neue Breite als Schild am Griff.
* Gesendet wird `rx_filter_band` (gedrosselt, beim Loslassen der letzte Stand); der
  Durchlass folgt Longpaths Gegenmeldung. Mindestbreite 50 Hz.
* Desktop: „Filterbreite" in Combined zeigt die gemeldete Breite, wenn keine Pille passt.
