# App: drei Layout-Entwürfe nach dem Mac-Foto (2026-11-21, Fassung v3)

Vorlage: Martins Bildschirmfoto von Mac-Longpath vom 21.11.2026 (liegt nicht im
Repository). „Es sollte so aussehen wie bei Longpath am MacBook." Die
Aufteilung bleibt fürs Telefon, Farben und Knopfform folgen dem Foto:

* **Grund schwarz/neutral**, Panelköpfe versal, ⚙ rechts oben im Kopf.
* **Knöpfe flach dunkel, dünner Rand, kein Glanzverlauf.**
* **Auswahl = orange gefüllte Pille mit dunkler Schrift** (USB, 20, 2.4k,
  SCHARF, Reiter). Messing bleibt für SENDEN.
* **Frequenz groß, orange**, Spots orange.
* **Spektrum blau/cyan** mit hellblauer Kante, **Wasserfall blau → grün → gelb.**
* **Regler:** schmale Rinne, kleiner blau umrandeter Griff, Zahl rechts.
* **S-Meter analog** mit orangem Zeiger, daneben „S8" orange.
* **Fußleiste:** TNF · MOX · VOX · TUNE · PS grau, Gerätename mittig, ON AIR rechts.

| Blatt | Idee |
| --- | --- |
| [1 — Ein Schirm](layout-1-ein-schirm.png) | alles sichtbar, nichts zu wischen |
| [2 — Reiter](layout-2-reiter.png) | großes Bild, Betrieb / Filter / Rotor als Reiter |
| [3 — Applet-Stapel](layout-3-applet-stapel.png) | wie die Applets am Mac, zuklappbar |

Hinweis: Die Auswahl als orange Pille widerspricht dem früheren Grundsatz
„Auswahl = Mulde" (Memory `design-kein-auswahl-blau`); das Foto zeigt sie
orange gefüllt, danach ist hier gerendert. Die Blätter sind aus der echten
Seite mit Zusatz-CSS gezeichnet, Wasserfall-/Spektrumfarben nur im Blatt.
Nichts an der App geändert. Die älteren Ordner `2026-11-21-layout` und
`2026-11-21-layout-v2` bleiben unberührt.
