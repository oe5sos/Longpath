# App: drei Layout-Entwürfe (2026-11-21)

Martin: Angleich ans Mac-Longpath heißt auch **Bildschirmaufteilung**, nicht nur
Farbe. Drei Entwürfe, je ein Blatt in iPhone-Größe (393 × 852, doppelte
Auflösung), mit echten Seitendaten aus der Attrappe. Gemeinsam:

* Frequenz in einem **Glaschip** (versenkt, wie das Frequenz-Applet am Mac),
* **Sendeleiste fest unten** im Daumenbereich: ENTSICHERN/SCHARF, SENDEN
  (Messing, Halten), TUNE (Halten) — die Haltetasten aus PR #507,
* Auswahl als Mulde, Orange wie das Plus am Mac.

| Blatt | Idee | Preis |
| --- | --- | --- |
| [1 — Ein Schirm](layout-1-ein-schirm.png) | alles sichtbar, nichts zu wischen; Regler in einer Zeile; Rotor als schmale Zeile | dichter, Rotorscheibe nicht sichtbar |
| [2 — Reiter](layout-2-reiter.png) | großes Bild; Betrieb / Filter / Rotor als Reiter darunter; S-Meter + Regler immer da | ein Tipp mehr bis zum Filter |
| [3 — Applet-Stapel](layout-3-applet-stapel.png) | wie die Applets am Mac: Versalzeile + Glaschip mit dem Wert, zuklappbar | Bild kleiner, mehr Zeilen |

Nichts an der echten App geändert; sie wird erst nach Martins Wahl umgebaut.
