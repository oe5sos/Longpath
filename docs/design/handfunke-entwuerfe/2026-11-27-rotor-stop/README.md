# Rotor STOP (2026-11-27)

`rotor_stop:` kennt Longpaths TCI-Server seit 2026-10-05, die App hatte keinen Knopf dafür.
STOP unter „AUF … DREHEN“, ohne Zwei-Griff-Sicherung (Anhalten schadet nie).
Ruhig grau; meldet der Rotor `dreht`, Messing-Rand. Kein Rot.
Bilder: attrappe.py --rotorfrei --rotorstand 255, Ziel 320° gewählt, Rotor läuft.
Gegenprobe: STOP bei 276° → bleibt bei 276°.
